# Plan 9.1: User Security Center, Multi-Device Management UI & Anomaly Alerts

## Objective
Elevate the Account & Security Center UI (`/dashboard/account`) into a financial-grade security dashboard. Display real-time active sessions from the PostgreSQL `sessions` table, full trusted device management (rename, trust, untrust, remove), a prominent "Force Logout from All Devices" action with confirmation, recent login history, and security alert banners.
