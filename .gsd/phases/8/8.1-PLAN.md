# Plan 8.1: Real-Time Anomaly & Threat Detection Engine

## Objective
Implement continuous anomaly detection and risk scoring for authentication events in `src/lib/security/anomaly-detector.ts`. Detect impossible travel, unrecognized devices, rapid IP/country switches, and brute-force behaviors. Calculate dynamic risk scores (0–100) and dispatch automated security notifications.

## Tasks

<task type="auto">
  <name>Build Anomaly Detection & Geolocation Calculation Engine</name>
  <files>
    src/lib/security/anomaly-detector.ts
  </files>
  <action>
    Create `src/lib/security/anomaly-detector.ts`:
    1. Geolocation & Impossible Travel Calculator:
       - Implement Haversine distance formula: calculate great-circle distance between coordinates $(lat_1, lon_1)$ and $(lat_2, lon_2)$ in kilometers.
       - Calculate travel velocity: $v = \frac{\Delta d}{\Delta t \text{ (hours)}}$.
       - If velocity $> 900 \text{ km/h}$ and $\Delta t < 4 \text{ hours}$, flag as `impossible_travel`.
    2. Device Fingerprint Anomaly:
       - Generate SHA-256 fingerprint hash of client characteristics (`userAgent`, `acceptLanguage`, screen parameters if provided).
       - Query user's known devices; if device fingerprint is unrecognized, flag as `new_device`.
    3. Country & IP Anomaly:
       - Compare login country against user's historical countries.
       - Flag `new_country` or `rapid_ip_switch` when IP subnet alters within short window.
    4. Brute-Force & Rate Limit Violations:
       - Track failed logins by IP and email identifier using sliding window.
       - If $> 5$ failures in 10 minutes, flag as `brute_force_suspected`.
    5. Risk Score Calculator (0–100):
       - Sum weighted risk penalties:
         - Impossible Travel: +60 points
         - New Country: +30 points
         - New Device: +25 points
         - Brute-Force Behavior: +50 points
         - Token Reuse: +100 points
       - Classify risk tier: `low` (<30), `medium` (30–69), `high` (70–89), `critical` (>=90).
  </action>
  <verify>
    npx tsc --noEmit
  </verify>
  <done>
    `anomaly-detector.ts` accurately computes Haversine distance, detects velocity anomalies, hashes device fingerprints, and scores risks deterministically.
  </done>
</task>
