  <action>
    Add dedicated, strongly-typed Drizzle tables and relations for enterprise session and device management:
    1. Define `sessions` table:
       - `id`: serial primary key
       - `publicId`: text unique notNull (prefix `sess_`)
       - `userId`: integer references `users.id` with cascade delete
       - `deviceId`: text (references `devices.publicId`)
       - `refreshTokenHash`: text notNull
       - `tokenVersion`: integer default 1 notNull
       - `ipAddress`: text
       - `userAgent`: text
       - `browser`: text
       - `os`: text
       - `deviceType`: text default 'desktop'
       - `country`: text
       - `city`: text
       - `region`: text
       - `status`: text default 'active' notNull ('active' | 'expired' | 'revoked')
       - `revocationReason`: text
       - `lastActiveAt`: timestamp defaultNow() notNull
       - `idleExpiresAt`: timestamp notNull
       - `expiresAt`: timestamp notNull
       - `createdAt`: timestamp defaultNow() notNull
       - `updatedAt`: timestamp defaultNow() notNull
       - Indexes on: `userId`, `publicId`, `refreshTokenHash`, `status`, `expiresAt`.
    2. Define `devices` table:
       - `id`: serial primary key
       - `publicId`: text unique notNull (prefix `dev_`)
       - `userId`: integer references `users.id` with cascade delete
       - `fingerprint`: text notNull
       - `name`: text notNull
       - `browser`: text
       - `os`: text
       - `deviceType`: text default 'desktop'
       - `lastIp`: text
       - `lastLocation`: text
       - `isTrusted`: boolean default false notNull
       - `firstSeenAt`: timestamp defaultNow() notNull
       - `lastActiveAt`: timestamp defaultNow() notNull
       - `createdAt`: timestamp defaultNow() notNull
       - `updatedAt`: timestamp defaultNow() notNull
       - Indexes on: `userId`, `fingerprint`, `publicId`, `isTrusted`.
    3. Define `securityAuditEvents` table:
       - Structured security logs: `id`, `publicId`, `userId`, `action`, `status`, `riskLevel` ('low'|'medium'|'high'|'critical'), `ipAddress`, `userAgent`, `browser`, `os`, `location`, `details` (jsonb), `createdAt`.
    4. Export relations and TypeScript inferred types (`Session`, `NewSession`, `Device`, `NewDevice`, `SecurityAuditEvent`).

    AVOID: Relying on JSONB blobs in `profiles` as the primary source of truth.
    USE: Normalized relational tables with B-Tree indexes for fast verification and instant query resolution.
