# Plan 7.3: Centralized Session Invalidation & Force Logout Engine

## Objective
Implement centralized session lifecycle and token revocation management in `src/actions/auth-session.ts` and `src/actions/account.ts`. Provide guaranteed immediate revocation for single session termination, idle timeout expiration, absolute expiration, password/email updates, and "Logout from All Devices" (Force Logout) with zero token reuse.

## Tasks

<task type="auto">
  <name>Build Centralized Session Revocation & Lifecycle Engine</name>
  <files>
    src/actions/auth-session.ts
  </files>
  <action>
    Build server-side session management functions:
    1. `terminateSession(sessionId: string, reason: string)`:
       - Validate that the session belongs to the authenticated user (or user is admin).
       - Update `sessions` row: set `status = 'revoked'`, `revocationReason = reason`, `tokenVersion = tokenVersion + 1`, `updatedAt = NOW()`.
       - Record audit event: `action: "session_terminated"`, `entityType: "session"`, `entityId: session.id`.
       - Invalidate in-memory session cache.
    2. `terminateAllOtherSessions(currentSessionId: string)`:
       - Terminate all sessions for the user where `publicId != currentSessionId` and `status = 'active'`.
       - Update their `status = 'revoked'`, `revocationReason = 'terminate_all_others'`.
       - Record audit event: `action: "sessions_terminated_all_others"`.
    3. `forceLogoutAllDevices(userId: number, reason = "user_force_logout")`:
       - Terminate ALL active sessions for the user: set `status = 'revoked'`, `revocationReason = reason`.
       - Increment `tokenVersion` or user token epoch to invalidate any extant access tokens.
       - Clear authentication cookies (`sl_access_token`, `sl_refresh_token`).
       - Record high-priority audit log.
    4. `validateSession(sessionId: string, tokenVersion?: number)`:
       - Query session by `publicId`.
       - Check if `status !== 'active'`, or `now > expiresAt`, or `now > idleExpiresAt`.
       - Check if `tokenVersion` mismatch exists.
       - If invalid, return `{ valid: false, reason: "revoked_or_expired" }`.
       - If valid, update `lastActiveAt = NOW()` (throttled to once every 2 minutes to minimize DB writes).
  </action>
  <verify>
    npx tsc --noEmit
  </verify>
  <done>
    Session invalidation reliably revokes single sessions, all other sessions, and all user sessions with database-backed status and token version bumps.
  </done>
</task>
